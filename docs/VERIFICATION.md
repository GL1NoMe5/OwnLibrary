# Проверка текущего выпуска

Проверки выполняются на Windows x64 с Electron 45. Зависимости зафиксированы lockfile. Blender-модели и 3D-рендеринг не входят в текущий этап по решению владельца.

## Автоматические проверки

`npm test` проверяет постоянство базы, первоначальные примеры, каскадное удаление дневников, проверки дат и оценок, конкурирующие изменения, отказ диска и повтор записи. Отдельно проверяются история редактора, изменения во время сохранения, повтор сохранения настроек, статистика, високосные годы и размещение 1000 книг.

`npm run build` выполняет TypeScript-проверку и сборку Main, Preload и Renderer.

`npm run test:e2e` запускает настоящее Electron-окно с отдельным временным профилем. Основной сценарий: офлайн-запуск, сворачивание меню, добавление книги с импортированной обложкой, удаление исходного изображения, заметка и рисунок, закрытие сразу после правки, повторный запуск, проверка записи, экспорт PNG с локальным изображением, создание и восстановление архива.

После `npm run build:win` дополнительные сценарии проверяют упакованный EXE и самораспаковывающийся portable. У дочерних процессов в PATH остаются только системные каталоги Windows; внешнего Node.js там нет. Проверяются загрузка SQLite WASM, библиотека и встроенные иллюстрации дневника.

В автоматических тестах ответы системных диалогов заменяются детерминированными путями; файловая запись, SQLite, PNG-композиция, локальный медиапротокол и архивирование выполняются настоящими реализациями.

## Визуальная проверка

Скриншоты библиотеки, дневника и карточки итогов получены из настоящего Electron-приложения и находятся в `docs/screenshots/`. Проверены локальные шрифты с кириллицей, встроенные иллюстрации, слои рисунков и предметов, книжный переплёт и цветовые темы интерфейса.

Непроверенные внешние условия: установка на отдельной чистой машине и разные физические дисплеи/DPI. Целевые ноутбуки и производительность 3D будут проверяться на следующем этапе.
