# Проверка текущего выпуска

Для 1.3.8 пройдены две целевые проверки: `unreadBooks.test.ts` (обновление настоящей схемы SQLite 1 до 2 с сохранением книг и разворотов, разбивка стопки на страницы, исключение из статистики, перенос на полку и повторное открытие базы) и `unread-stack.spec.ts` (реальный Electron, вкладка непрочитанных, ракурс стопки, Raycaster-клик по книге, запись в дневник, перенос в прочитанные с сохранением записи). Проверка Electron завершилась за 10,7 с, на отдельном временном профиле. Визуально проверено расположение стопки относительно кресла и столика. Скриншот: `docs/screenshots/unread-stack.png`.

TypeScript, production-сборка и упаковка Windows 1.3.8 прошли. Portable — 231 132 142 байт, установщик — 231 377 569 байт. JS/CSS и ассеты в ASAR сверены с текущей сборкой, встроенный ASAR portable совпадает с упакованным приложением; GLB комнаты и кота прежние, стопка формируется из данных библиотеки в runtime. Чистая установка на другом компьютере не проверялась.

В 1.3.7 две проверки `tests/unit/interfaceTheme.test.ts` подтвердили чтение прежних настроек без поля темы, сохранение всех трёх вариантов в SQLite после повторного открытия и восстановление старого/нового ZIP-архива. Существующие настройки комнаты и читательские цели при этом сохраняются.

Один целевой сценарий `tests/e2e/interface-themes.spec.ts` прошёл в настоящем Electron за 6,5 с: переключение новых тем, библиотека, форма книги, настройки, цитаты, прогресс, итоги чтения, дневник и кадрирование, сохранение темы после перезапуска, отключение анимаций как настройкой, так и системным reduced motion. Проверены отсутствие ошибок renderer, неизменность исходного разворота и цветов обложек. Контраст основного и вторичного текста к поверхности панели выше 4,5 для обеих новых тем. Снимки основных экранов просмотрены; использован отдельный временный профиль, личная библиотека не изменялась.

Предпросмотры новых тем: `docs/screenshots/theme-dark.png` и `docs/screenshots/theme-christmas.png`. README и исходники/модели комнаты этой итерацией не менялись.

## Автоматические проверки

`npm test` проверяет постоянство базы, первоначальные примеры, каскадное удаление дневников, проверки дат и оценок, конкурирующие изменения, отказ диска и повтор записи. Отдельно проверяются история редактора, изменения во время сохранения, повтор сохранения настроек, статистика, високосные годы и размещение 1000 книг.

`npm run build` выполняет TypeScript-проверку и сборку Main, Preload и Renderer.

`npm run test:e2e` запускает настоящее Electron-окно с отдельным временным профилем. Основной сценарий: офлайн-запуск, сворачивание меню, добавление книги с импортированной обложкой, удаление исходного изображения, заметка и рисунок, закрытие сразу после правки, повторный запуск, проверка записи, экспорт PNG с локальным изображением, создание и восстановление архива.

Сценарий комнаты дополнительно проверяет загрузку моделей офлайн, реальный Raycaster-клик, приостановку за дневником, поиск книги, переключение страниц коллекции, Low/High, импортированную обложку и восстановление доступа к библиотеке при потере графического контекста. Для обоих шкафов High проверяется фактическая неоднородность изображения: одних draw calls и координат камеры недостаточно для обнаружения пустого кадра. Проверяется общий переключатель праздничных огней. Модульные проверки связывают исходную раскладку с реальными размерами восьми ниш и проверяют 1000 книг.

После `npm run build:win` дополнительные сценарии проверяют упакованный EXE и самораспаковывающийся portable. У дочерних процессов в PATH остаются только системные каталоги Windows; внешнего Node.js там нет. Проверяются загрузка SQLite WASM, библиотека, GLB комнаты с книгами и встроенные иллюстрации дневника.

`tests/e2e/audio.spec.ts` проверяет локальное декодирование записей, отсутствие пауз на стыках дождя, камина и музыкальной петли, изменение громкости без перезапуска и выключение во время загрузки. В версии 1.3 реальный Raycaster-клик по радио дополнительно проверяет паузу и продолжение с ненулевого сохранённого смещения без уведомлений.

В автоматических тестах ответы системных диалогов заменяются детерминированными путями; файловая запись, SQLite, PNG-композиция, локальный медиапротокол и архивирование выполняются настоящими реализациями.

## Визуальная проверка

Скриншоты библиотеки, комнаты, дневника и карточки итогов получены из настоящего Electron-приложения и находятся в `docs/screenshots/`. Проверены локальные шрифты с кириллицей, встроенные иллюстрации, слои рисунков и предметов, книжный переплёт и цветовые темы интерфейса.

Непроверенные внешние условия: установка на отдельной чистой машине и разные физические дисплеи/DPI. 30 FPS на Iris Xe/Vega ещё требуют физического замера; автоматические проверки не подменяют такой замер.
