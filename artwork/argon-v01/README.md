# Исходная комната Argon v01

Оригинальные Blender 5.2 проекты скопированы из авторского пакета `OwnLibrary-3D/argon/v01` без изменения геометрии и материалов. Текстуры упакованы в `.blend`. Авторский отчёт о происхождении находится в `resources/licenses/room/PROVENANCE.md`. Рабочие GLB лежат в `src/renderer/public/room/` и также сохранены без изменений.

SHA-256:

- `sanctuary-room.glb`: `36033132a57e9f3132f1264f35e7a414872f8a1cecf4fb8d7cd999fd48ead57e`
- `sanctuary-cat.glb`: `7473d253ab9d48cdef87efa8aaea610f3ec6cf77ac3280dad01f9ebf483d4861b`

При следующей художественной итерации сохраняйте отдельную версию. Сохраняйте имена узлов, координаты зон полок, камеры и клипы кота. Перед заменой GLB повторите проверки, описанные в `docs/ROOM.md`.

Для ручного повторного экспорта используйте glTF 2.0 Binary с текстурами, custom properties и координатами Y Up. В исходнике комнаты экспортируется коллекция `SanctuaryRoom`, без `PreviewBooks`, `PreviewFX`, `SceneLighting` и кота; в отдельном исходнике кота — его меш и арматура с двумя клипами. Не экспортируйте демонстрационные книги в окружение.
