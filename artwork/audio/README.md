# Звук настольного радио

`render_radio.py` создаёт текущую инструментальную аранжировку Jingle Bells:
16 тактов при 72 BPM, 53⅓ секунды. Тихое пианино из банка VSCO 2 CE, мягкий
ритм, джазовые аккорды и приглушённый верх; хвосты нот и реверберации переходят
через границу петли без изменения темпа. Исполнение оригинальное, без вокала.

Для повторного рендера нужен Python с NumPy; подойдёт Python из Steam Blender:

```powershell
& 'D:\SteamLibrary\steamapps\common\Blender\5.2\python\bin\python.exe' artwork/audio/render_radio.py
```

Скрипт скачивает только восемь нужных сэмплов в игнорируемую `.local/audio-sources/`
и сохраняет `src/renderer/src/assets/audio/jingle-bells-radio.wav`. Сеть нужна лишь
для повторного создания ассета; готовое приложение полностью автономно.

Мелодия Jingle Bells находится в общественном достоянии. Сэмплы VSCO 2 CE
распространяются по CC0 1.0; аранжировка и готовая запись созданы для проекта.
Происхождение и ссылки на авторов находятся в `resources/licenses/audio/PROVENANCE.md`.
