# Происхождение праздничной комнаты v03

Интерьер и кот основаны на оригинальном пакете Argon v01 для OwnLibrary. Праздничные ёлка, подарки, носки, венок, украшения и процедурные карты взяты из следующей авторской версии Argon v02.

Codex v03 изменяет геометрию хвои, складки текстиля, добавляет кант кресла, уточняет материалы и реализует ночное освещение и отражения в Three.js. Источник — `artwork/codex-v03/source/sanctuary-room.blend`, скрипт изменений — `artwork/codex-v03/scripts/refine_room.py`. Кот из v01 сохранён без изменений.

Новые скачанные модели, фототекстуры, внешние HDRI и платные генерации для v03 не использовались. Карта отражений генерируется приложением локально из простого вспомогательного окружения. Three.js распространяется по MIT; его лицензия включена отдельно.
